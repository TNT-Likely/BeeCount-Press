# 抖音 4.0 上线封面

抖音发布 4.0 宣传视频用的封面，2026-11-15 定稿。风格基准为小红书笔记
《蜜蜂记账 4.0 昨晚正式上线了》的封面：米色底 + 白色毛笔字 + 真实界面截图。

## 成品

| 文件 | 用途 | 尺寸 |
| --- | --- | --- |
| `douyin-cover-vertical.png` | 竖版封面，直接采用小红书原封面，未改动 | 1080 × 1419（≈3:4） |
| `douyin-cover-horizontal.png` | 横版封面，由 `index.html` 渲染 | 1440 × 1080（4:3） |

抖音封面规范：竖版 3:4、横版 4:3（核对日期 2026-11-15）。竖版与标准
1080 × 1440 差 21px，上传时抖音按 3:4 轻微裁切即可。

## 横版构成

- 背景 `#E3D8CA`（从原封面取色，平色）；毛笔字白色 `#FDFBF7`
- 左侧竖排两列，同字体同色：主列「蜜蜂记账」大字，逐字微旋转仿手写；
  副列「4.0 / 上 / 线」小字，底部对齐（书法落款位），「4.0」横排组嵌入竖列
- 右侧两张真实页面截图阶梯错落：首页明细（后）+ 记账键盘（前、主图），
  直接引用 `../../store/v4/raw/ios-medium/zh/light/` 的 01-home 与
  05-transaction，不另存副本

## 字体

马善政毛笔楷书（Ma Shan Zheng，Google Fonts，SIL OFL 1.1，可商用），
原件在 `assets/MaShanZheng-Regular.ttf`，以 `-webkit-text-stroke`
（8px/4px）加粗笔画。来源：<https://fonts.google.com/specimen/Ma+Shan+Zheng>

## 重新渲染

浏览器打开 `index.html`，窗口设为 1440 × 1080 截图即得成品。
字体为相对路径加载，`file://` 双击即可使用。
