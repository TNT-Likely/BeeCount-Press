## BGM 建议

- **节奏**:慢 60-70 BPM,Lo-Fi 钢琴
- **抖音音乐库关键词**:「治愈生活 / 慢节奏 / 钢琴 vlog」
- **节拍点**:在 12s 数字揭示瞬间用 BGM 突然停顿 0.5s,然后回归(增强冲击)

---

## 字幕样式

- 主旁白字幕:**白色 80px + 黑色描边**,底部 1/4
- 数字 ¥3,478:**蜂蜜橙 #F4A82B + 200px 加粗**,屏幕正中
- 「全是星巴克 🥲」:用**手写体感字体**(可选 Caveat / Pacifico),60px,自然摆放

---

## Hook 钩子分析

为什么前 3s 留白配合咖啡蒸气?
- 留悬念 → 观众想知道发生了什么 → 滑动概率降低
- 治愈视觉先建立信任(不是「卖货」感的开头)
- 第二镜头才出现产品截图,转化路径自然

## 后期 ffmpeg 模板(参考)

```bash
# 假设各 clip 已剪好,要批量贴字幕
ffmpeg -i clip-1.mp4 -i clip-2.mp4 ... \
  -filter_complex "
    [0:v][1:v]concat=n=N:v=1[v];
    [v]subtitles=01.srt:force_style='FontName=PingFang SC,FontSize=24,PrimaryColour=&Hffffff&,OutlineColour=&H000000&,Outline=2'[outv]
  " \
  -map "[outv]" -c:a copy out.mp4
```

字幕文件 `subtitles/01-data-reveal.srt` 需要单独写。
