# BeeCount 抖音视频拍摄总计划

> **基调**:治愈系 + 生活感。**不要**特效炸场,要静谧、温暖、真诚。
> **格式**:9:16(1080×1920)。
> **节奏**:6 条短(15-30s)+ 1 条长(60s VLOG 风),周更 2 条。

---

## 总体素材体系(三卷)

### A 卷 — 空镜 / 静物(治愈感氛围)

最重要,占视频开头 2-3 秒钩子位。**任何一支视频都从 A 卷起头**。

| 镜头 ID | 内容 | 时长 | 备选道具 |
|---|---|---|---|
| A-01 | 早晨阳光透过窗帘洒在桌面 | 3s | 飘动窗帘、桌面木纹 |
| A-02 | 一杯刚冲好的咖啡,蒸气往上飘 | 3s | 拿铁拉花 / 手冲玻璃壶 |
| A-03 | 翻开纸质账本 + 一支笔放在旁边 | 3s | 牛皮纸本 / Moleskine |
| A-04 | 手指轻轻翻动手机,灯光柔和 | 3s | 米色抓绒 / 阳台逆光 |
| A-05 | 一只手拿手机走过早餐桌 | 3s | 桌上有橙汁 / 面包 |
| A-06 | 桌面摆「咖啡 + 钥匙 + 钱包 + 手机」flat-lay | 3s | 慢慢俯拍,微微移动 |
| A-07 | 阳台 / 落地窗 + 植物 + 手机静放 | 3s | 龟背竹 / 散尾葵 |
| A-08 | 黄昏台灯下打开手机,屏幕亮起 | 3s | 暖光 3000K |
| A-09 | 手指划过手机屏幕的特写 | 2s | 自然光 / 慢动作 |
| A-10 | 笔在账本上写「💐 今天花了 ¥xx」 | 3s | 手写治愈感 |

**拍摄要点**:
- 全部用**自然光**(早 9 点 / 黄昏)拍,避免顶灯白光
- **景深浅**(光圈 f/1.8-2.8),前景虚化营造氛围
- **色调**:奶油 + 蜂蜜 + 暖灰,后期统一调成偏黄(**不要冷蓝**)
- 每个镜头**多录 2-3 个 take**,后期挑

### B 卷 — 屏幕录制 / app 操作

证明产品力,占视频 30-50% 时长。

| 镜头 ID | 内容 | 时长 | 已有素材 |
|---|---|---|---|
| B-01 | 长按 + 号弹出菜单,3 种记账方式 | 4s | 需录 |
| B-02 | AI 对话「中午吃了 38 块的麻辣烫」→ 自动识别 → 入账 | 8s | 需录 |
| B-03 | 拍照识别支付截图 → 自动填金额 | 6s | 部分有(`demo/videos/zh/02-ocr-recognition.mp4`)|
| B-04 | 月度报表打开 → 饼图 → 趋势图滑动 | 6s | 部分有(`demo/videos/zh/04-data-analysis.mp4`)|
| B-05 | 切换账本(个人 / 家庭 / 出差)| 4s | 需录 |
| B-06 | 云服务页 → 5 种选项展示(滚动) | 5s | 需录(突出 BeeCount Cloud / WebDAV / S3) |
| B-07 | 资产管理页 → 净资产 → 资产构成圆环 | 5s | 需录 |
| B-08 | 标签管理 → 彩色标签 grid → 点击筛选 | 4s | 需录 |
| B-09 | CSV 导入 → 微信 / 支付宝账单识别 | 6s | 部分有(`demo/videos/zh/03-import-ledger.mp4`)|
| B-10 | 暗黑模式切换效果 | 3s | 需录 |

**录屏方式**:
- iOS:控制中心 → 屏幕录制(60fps),后期裁成 9:16
- Android:`adb shell screenrecord --bit-rate 8000000 --time-limit 30 /sdcard/clip.mp4`
- **关键**:操作前**先把测试账本数据准备齐全**(用 `scripts/gen_store_test_data.py` 生成的 CSV 导入)
- 操作**慢一点**,每步停 1 秒让观众跟得上
- 录完后用 ffmpeg 加 9:16 黑边或裁切:
  ```bash
  ffmpeg -i clip.mp4 -vf "scale=1080:-1,crop=1080:1920" out.mp4
  ```

### C 卷 — 真人 / 半身出镜(可选)

人格化、信任感,占视频 0-30%。如果不想露脸,可以只拍**手部 + 背影 + 桌面**。

| 镜头 ID | 内容 | 时长 |
|---|---|---|
| C-01 | 半身坐姿,看着手机讲解(配旁白) | 10s |
| C-02 | 手部特写:食指点击屏幕 | 3s |
| C-03 | 真人喝咖啡 + 眼神看到屏幕的微笑反应 | 3s |
| C-04 | 背影:坐在阳台看手机 | 3s |
| C-05 | 双手捧手机展示给镜头 | 3s |

**口播稿原则**:
- 短句、口语化、不要书面语
- 第一句必须是 **hook**(引发兴趣的悬念 / 痛点 / 反差)
- 不要直接说「这是 XXX 软件」,要说「最近我发现一个...」「最近被一个 App 治愈了...」

## 视频后期统一规范

### 字幕

- **字体**:思源黑体粗体 + 80px 大小
- **颜色**:白色文字 + 黑色 1px 描边(治愈感)
- **位置**:**底部 1/4 处**,不要顶部(避开抖音 UI)
- **节奏**:每句字幕在屏 2-3s,跟旁白严格对齐
- **强调**:关键字加蜂蜜橙(`#F4A82B`)

### BGM

- **方向**:Lo-Fi / 钢琴小品 / Indie Pop 治愈调
- **库**:抖音音乐库选「治愈系 / 生活 / Vlog」类带版权许可的
- **不要**:用流量神曲,会被算法判定为搬运
- **音量**:旁白时 BGM -12dB,无旁白时 -6dB

### 转场

- **避免**炫技转场(光闪 / 玻璃破碎),用**简单 fade / cut** 即可
- 镜头之间留 0.3-0.5s 黑场作呼吸

### 调色

- LUT 推荐:**Moody Cream / Honey Glow** 类,加暖
- 整体色调:**+5 暖色温、+10 高光、-5 阴影**
- 高光偏黄,阴影微暖

### 封面

- 复用小红书封面 1-2 张,改成 9:16 即可
- **核心**:封面文字必须**第一眼能看清**(主标 ≥ 60px)
