# BeeCount 3.0 宣发物料

> 治愈系 + 生活感主基调,小红书图文 + 抖音短视频双平台。

## 目录结构

```
marketing/
├─ xiaohongshu/
│  ├─ covers/         9 张主题封面 HTML 模板(3:4 / 1242×1656)
│  ├─ info-cards/     6 张信息图 HTML 模板(1:1 / 1242×1242)
│  ├─ assets/         shared CSS / 字体 / 公共素材
│  └─ output/         渲染产物 PNG(打包上传用)
├─ douyin/
│  ├─ scripts/        每条视频的镜头脚本(.md)
│  ├─ raw-clips/      你录制 + 素材库(空镜 / 屏录 / 真人)
│  ├─ subtitles/      字幕文件(.srt 烧录用)
│  ├─ bgm/            备选 BGM(版权问题自行确认)
│  └─ output/         FFmpeg 合成的最终 mp4
└─ copy/              文案库(标题 / 正文 / tag)
```

## 使用流程

### 渲染图片(等 puppeteer MCP 装好后)

```bash
make xhs-render   # 启 http server + headless 渲所有 HTML 模板 → output/
```

或本地手动:

```bash
python3 -m http.server 8000
# 浏览器开 http://localhost:8000/marketing/xiaohongshu/covers/01.html
# 用 Cmd+Shift+4 截图,或用浏览器扩展(Save Page WE)保存
```

### 视频拼接

```bash
make video-cut    # 用现有 demo/videos 转 9:16 + 加字幕 + 拼接
```

## 工时估算

| 阶段 | 工时 | 备注 |
|---|---|---|
| 图片(15 张)模板 + 渲染 | 1 天 | 我做模板 + 你审稿 |
| 视频(6 条)A/B/C 卷拍摄 | 1.5 天 | 你录,清单见 douyin/scripts/ |
| 视频后期(剪辑 + 字幕) | 0.5 天 | 我给 ffmpeg 脚本,你跑 |
| 文案库(标题 + 正文 + tag) | 0.5 天 | 我给,你微调口语 |
| **合计** | **3.5 天** | |

## 投放节奏建议

- **小红书**:每 2 天发 1 张图文,15 张 = 1 个月。优先发"开源 / 自托管 / 数据自主"主题(差异化卖点)
- **抖音**:每 3 天发 1 条短视频,前 3 条要密集冲流量找数据。
- **互动**:评论区准备好回复模板,前 30 分钟最关键(算法判活跃度)
